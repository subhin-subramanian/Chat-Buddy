# CHAT-BUDDY
**Chat-Buddy** is a modern, scalable chat application built using **Next.js and TypeScript**, inspired by real-world messaging platforms like **WhatsApp and Instagram DMs**.This project showcases a full-stack + frontend-first approach using **Typescript,React and Next.js**.

## ⚙️ Getting Started
1️⃣ Clone the repo
```
git clone https://github.com/subhin-subramanian/Chat-Buddy.git
cd Chat-Buddy
```
2️⃣ Install dependencies
```
npm install
```
3️⃣ Run locally
```
npm run dev
```
🌐 Open → http://localhost:3000
